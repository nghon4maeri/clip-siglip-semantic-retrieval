# Semantic Retrieval

**Semantic retrieval nói chung**
Folder này rộng hơn problem/.
problem/ hỏi bài toán là gì.
semantic-retrieval/ hỏi: "Người ta đã giải bài toán semantic retrieval như thế nào?"

Nghiên cứu:
- semantic search
- semantic retrieval
- dense retrieval
- embedding-based retrieval
- vector similarity
- semantic matching
- approximate nearest neighbor
- vector database

Ví dụ:
Text -> Embedding -> Vector Space -> Similarity Search -> Top-K

Nó giúp bạn hiểu retrieval mechanism trước khi đi sâu vào CLIP/SigLIP.
