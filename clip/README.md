# Nghiên cứu CLIP

Đây là một trong hai folder quan trọng nhất. Nó chỉ tập trung vào CLIP.

Cần nghiên cứu:
- CLIP architecture
- image encoder
- text encoder
- embedding
- contrastive learning
- training objective
- zero-shot learning
- image-text similarity
- CLIP retrieval
- các biến thể/follow-up quan trọng

Paper trung tâm: *Learning Transferable Visual Models From Natural Language* (Radford et al.)

**Quan trọng:** clip/ không phải nơi chứa source code CLIP. Source code implementation nên nằm ở project code, ví dụ: `src/models/clip.py`.
Còn `clip/` (ở đây) là nơi nghiên cứu paper và implementation reference.
