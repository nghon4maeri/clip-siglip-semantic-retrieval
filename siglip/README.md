# Nghiên cứu SigLIP

Đây là folder quan trọng thứ hai. Tương tự CLIP nhưng dành cho SigLIP.

Paper chính: *Sigmoid Loss for Language Image Pre-Training*

Nghiên cứu:
- SigLIP architecture
- sigmoid loss
- khác biệt với CLIP contrastive loss
- image encoder
- text encoder
- embedding
- similarity/scoring
- SigLIP retrieval
- SigLIP 2

Điểm quan trọng nhất bạn muốn hiểu:
CLIP -> Contrastive Softmax Loss
SigLIP -> Sigmoid Loss
Sau đó mới benchmark: CLIP vs SigLIP.
